# Synthetic Singapore and Malaysia Portraits

This dataset contains ten fictional adults (P011-P020). `identities.json` and `identities.csv` give fictional names, genders, nationalities and prompted cultural backgrounds. These labels are scenario metadata, not attributes inferred from appearance; the portraits do not represent the diversity of either country. Any resemblance to a real person is unintended.

`images/P0XX.jpg` holds each original reference portrait, also used as the first enrollment image. `variants/P0XX/` contains identity-conditioned edits for the remaining conditions. `manifest.json` records each image and the intended enrollment or recognition split. The first three conditions are for enrollment; the other eight are test queries. Never use query images to construct enrollment templates. The images are edits of a shared reference, not independent photographic captures, and there are no unknown identities; this dataset cannot measure unknown-person rejection or real-world performance. Contact sheets are review artifacts and are not benchmark images.

The OpenAI built-in image tool generated each reference and edited variant. Model version, seed and precise generation timestamp were not exposed. The prompt requested the same facial geometry and age while changing one pose, expression, glasses, lighting, background or camera distance; generations may nevertheless drift. Some generated-output mappings were recovered by timing and visual inspection; their provenance files identify this. Inspect all contact sheets before use.

Run `python validate.py` from this directory after installing Pillow, NumPy and OpenCV with face modules and setting `WASM_FACE_VALIDATION_MODELS` to a local directory containing the OpenCV Zoo YuNet 2023mar and SFace 2021dec ONNX files. See `../synthetic-faces-v1/opencv_adapter.py` for filenames. Automated detections and cosine similarity distributions do not establish identity consistency or a universal matching threshold. See `validation-report.json` for actual results and outstanding issues.
